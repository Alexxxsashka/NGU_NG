# Оновлення звітного кабінету НГУ

Головна сторінка використовує кадр вечірнього шикування у Форт-Занкудо. Емблема, темна палітра, жовті акценти та шрифти Roboto Condensed і Inter перенесені у навігацію, форми й таблиці.

Гравець реєструється за логіном, ім’ям, Static ID і паролем. Реєстрація резервує Static ID до розгляду заявки. Номери на кшталт 00741 і 741 вважаються одним ID. Історія кадрового профілю стає доступною після підтвердження заявки. Старі акаунти можуть продовжувати входити за своїми логінами.

У меню **Особовий склад → Доступ до кабінету** адміністратор може знайти акаунт, змінити ім’я, логін і Static ID непідтвердженої заявки, видалити акаунт, видати тимчасовий пароль або надати чи відкликати права адміністратора. Видалення звільняє Static ID і прибирає доступ до акаунта. Звіти, кадрові профілі та записи аудиту зберігаються.

Після видачі тимчасового пароля старий пароль і сеанси скасовуються. Тимчасовий пароль показується адміністратору один раз. Гравець входить із ним і задає новий пароль в особистому кабінеті. Для входу після зміни використовується новий пароль.

Перед запуском оновленої версії застосуйте міграцію до бази цього середовища командою `pnpm db:migrate`. Міграція додає ознаку обов’язкової зміни пароля й оновлює зв’язки акаунтів з історичними записами.
