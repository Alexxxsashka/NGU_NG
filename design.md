# Дизайн порталу НГУ · NG GTA 5 RP

## Джерела та напрям

Головний сайт задає чорне тло, бірюзові інтерактивні акценти й контрастний світлий текст. У його опублікованому CSS є акценти #46EDE2 і #2FE0D1, фон #020202 та Inter. [Сайт NG GTA 5 RP](https://ng-gta5.com/) · [Стилі сайту](https://ng-gta5.com/styles-GR2UNLI5.css)

Скриншот кабінету задає орієнтир для темних бірюзових поверхонь, тонких контурів і виразної основної кнопки. Постери підказують роботу зі світлом, емблемою НГУ та кінематографічним кадром. Для порталу зберігаємо фотографії бійців, обкладинки підрозділів і мотиви Форт-Занкудо.

## Палітра порталу

| Токен | Значення | Застосування |
|---|---|---|
| `--paper` | `#050C0D` | Тло сторінки та полів |
| `--surface` | `#0D1C1D` | Картки, звіти, модальні вікна |
| `--raised` | `#13292A` | Заголовки таблиць, фільтри, наведення |
| `--sidebar` | `#081415` | Бічна навігація |
| `--line` | `#29494A` | Межі панелей і рядків |
| `--control-line` | `#537C7D` | Контури полів вводу |
| `--accent` | `#46EDE2` | Основні кнопки, посилання, активні вкладки та фокус |
| `--accent-soft` | `#83DDD6` | Піктограми та службові акценти |
| `--ink` | `#F1FAF9` | Основний текст |
| `--muted` | `#A9C3C3` | Пояснення та другорядні підписи |
| `--on-accent` | `#041313` | Текст на суцільній бірюзовій кнопці |

Темні поверхні й додаткові відтінки підібрані для порталу. Бурштиновий зарезервований для очікування й уточнень, зелений для підтверджень, червоний для помилок і відхилень. Кожен статус має текстову назву. Синьо-жовтий прапор зберігає свої кольори.

## Типографіка й оформлення

- Inter для інтерфейсу, форм, підписів і таблиць. Roboto Condensed для коротких заголовків і позначення НГУ.
- Темна бічна панель із бірюзовим маркером активного пункту. Обкладинки й картки можуть мати м’яке світіння по контуру. Поля та таблиці використовують рівні поверхні для читабельності.
- Основна дія має суцільну бірюзову заливку. Другорядні кнопки мають контур, активна вкладка має виразну межу, а клавіатурний фокус позначається окремим кільцем.
- Зображення бійців та емблеми позначають розділи й підрозділи. Написи поверх фото мають темний градієнт під текстом. Навігаційні картки містять назву й короткий опис українською.
- На телефоні картки й кнопки переносяться, а широкі таблиці прокручуються в межах контейнера. Заголовки, підписи і стани залишаються доступними з клавіатури.

Спільні токени та стилі компонентів визначені в `NGU_NG/src/app/globals.css`. Векторна емблема порталу використовує той самий бірюзовий акцент.
